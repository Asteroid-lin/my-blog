# 履约中心

履约中心负责决定“这个订单应该如何被完成”，连接订单中心、库存中心、WMS 和物流。

## 订单履约全链路

```text
订单产生 → OMS 审核 → 履约决策 → 生成发货任务 → WMS 执行 → 物流配送 → 状态回传
```

## 寻仓与库存分配

根据客户地址、仓库库存、商品属性和履约成本选择发货仓。库存分配通常先锁定库存，真正扣减由 WMS 出库完成触发。

## 拆单与合单

一个订单的商品分布在多个仓库时，履约中心按仓库拆分子订单；同一客户、同一仓库的订单满足规则时可以合并发货。

## 快递匹配与供应商直发

根据地区、商品体积、时效和承运商规则匹配快递。无库存或指定供应商履约的商品，可以走供应商直发并回传物流状态。

## OMS 与 WMS 的边界

- OMS 关注哪个仓发、是否拆单、库存如何分配以及选择哪个物流。
- WMS 关注库内货位、拣货、复核、包装和出库执行。
