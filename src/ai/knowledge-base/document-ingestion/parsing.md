# 文档解析与标准化

解析负责把原始文件转换为结构化内容，同时保存“这些文字来自哪里”。输入是已登记且可以读取的文件版本，输出是标准内容、来源定位信息和质量报告。所属场景：[文档上传入库](./README.md)。

## 业务边界

知识维护人员关心正文有没有丢、表格是否正确、引用能否定位。解析组件只提供提取能力，文档是否达到可发布标准由业务规则判定。接口返回成功但正文为空、页数明显缺失，均不能直接进入发布。

本专栏采用“原始文件保留、解析产物按版本生成”的基线。升级解析器时生成新的处理结果，避免无法解释历史回答曾引用哪份内容。

## 文件类型与处理策略

| 类型 | 核心处理 | 重点核对 |
| --- | --- | --- |
| 文本型 PDF | 提取文字、段落、阅读顺序 | 多栏、页眉页脚、跨页段落 |
| 扫描 PDF、图片 | 识别文字与版面 | 模糊、旋转、手写、表格单元格 |
| Word | 提取标题、正文、列表、表格 | 修订、批注、页码稳定性 |
| Markdown、文本 | 保留层级、列表和代码块 | 编码、外链、相对图片资源 |
| 表格类文档 | 结合表头与行列含义转换 | 单位、合并单元格、公式结果 |

类型清单是设计范围，实际支持能力需按所选解析器验证。没有稳定页码的文件使用章节路径、段落序号或单元格范围定位，不能伪造 PDF 页码。

## 正常业务流程

1. 按文件记录读取对象，并核对文件版本、大小或摘要，确保处理的是受理时的内容。
2. 识别文件类型、文本层和语言，选择与文档相匹配的解析策略。
3. 按页或逻辑单元处理，保留正文、标题层级、列表、表格、图片说明及顺序。
4. 将组件特有结构转成内部标准内容，统一编码、空白和换行表达。
5. 为每个内容块记录来源位置，建立原始文件与解析产物的映射。
6. 生成质量报告：识别页数、有效内容块、空白页、失败页、表格数量和告警。
7. 按质量门槛进入切分、人工复核或失败处理。部分解析成功必须保留缺失范围。

图片没有可识别文字且未启用图像理解时，只能保留图片及位置，不应虚构图片描述。正文中的链接是内容；是否抓取链接目标应属于另外经过授权的数据接入动作。

## 标准内容与关键数据

| 数据 | 用途 |
| --- | --- |
| 文档标识、内容版本 | 保证所有产物归属明确 |
| 解析任务、解析器版本、规则版本 | 解释相同文件为何产生不同结果 |
| 内容块标识、类型、顺序 | 组织标题、段落、表格和图片 |
| 标题路径 | 给片段提供所属章节 |
| 原文定位 | PDF 页码和区域、章节路径或表格位置 |
| 标准正文、表格结构、资源引用 | 供清洗、展示和切分使用 |
| 质量报告与失败范围 | 支撑人工复核和选择性重试 |

机器识别的置信分值可以辅助筛查，但不同解析器的数值不应直接混用。发布门槛应结合业务样本确认。

## 关键业务规则

数字、日期、金额、单位、否定词和适用条件是重点保护内容。例如“超过 7 天不支持无理由退货”不能因识别错误变成“超过 7 天支持退货”。制度文档的表格列名必须与单元格一起保留，避免“30”失去“工作日”的单位。

正文中存在“忽略规则”“导出所有资料”等文字时，只作为待处理文档内容，不作为系统指令。解析过程不执行嵌入脚本、宏或文档指令。

## 部分成功与人工复核

| 结果 | 建议处置 |
| --- | --- |
| 全文完整、结构可用 | 进入清洗切分 |
| 非关键图片说明缺失 | 按知识库规则告警，复核后决定是否接受 |
| 关键表格或制度条款缺失 | 阻止发布并标记需要复核 |
| 文件损坏、密码不可用 | 终止本次处理，要求替换文件 |
| 少量页面临时解析失败 | 重试失败范围，合并后重新做全量质量检查 |

人工修正不能直接改掉原始文件记录。应形成有操作者、时间和理由的修订产物，必要时作为新的内容版本处理。

## 业务示例

《寄修操作规范》共 12 页，其中第 8 页为收费标准表。解析得到 11 页正文和一个空表格。任务应显示“解析待复核：第 8 页表格缺失”，不能仅因正文有数千字就判为成功。补充清晰文件后重建解析结果，再验证收费单位、适用机型和备注是否完整。

## 验收场景

| 样本 | 验收要点 |
| --- | --- |
| 双栏 PDF | 阅读顺序不左右交错，段落能连续理解 |
| 扫描件含倾斜页面 | 缺失与低质量区域能被定位并提示 |
| 表格跨两页 | 表头、续表、单位与行关系保留 |
| Word 无固定页码 | 引用使用稳定章节或段落定位 |
| 解析服务超时后重试 | 同一输入版本不会混入其他版本的内容 |
| 成功响应但正文为空 | 被质量检查拦截，不进入可用状态 |

## 实施前需要确定

确认解析组件的格式支持、扫描件质量门槛、关键表格复核责任人、人工修订权限，以及原文预览能否展示解析定位。
