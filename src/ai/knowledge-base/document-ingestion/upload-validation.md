# 上传与校验

本模块把用户提交的文件转为可追踪的文档和处理任务。上传成功仅表示原始文件已经可靠保存，能否参与问答还取决于解析、索引和发布结果。所属场景：[文档上传入库](./README.md)。

## 业务目标与参与角色

知识维护人员选择目标知识库、填写业务标题并上传文件；知识库管理员维护可接收类型、容量和发布规则；系统负责权限校验、文件存储、去重提示和任务登记。上传人不因上传行为自动获得知识库的授权管理权限。

典型例子：售后主管上传《寄修操作规范》，原文件名为“售后制度_最终确认_03.pdf”。页面展示业务标题，下载保留原始文件名，后续更新仍围绕同一个文档身份进行。

## 输入、输出与前置条件

| 信息 | 业务含义与规则 |
| --- | --- |
| 租户与操作者 | 来自可信登录上下文，不能相信任意传入的租户编号 |
| 目标知识库 | 必须存在、启用，且操作者具有新增文档权限 |
| 业务标题 | 面向搜索、管理列表和引用展示，可独立于文件名维护 |
| 原始文件名 | 记录原始来源；存储对象键由系统生成，不能直接拼接用户路径 |
| 文件内容与摘要 | 内容用于处理，摘要辅助完整性核对和重复内容识别 |
| 请求标识 | 表达一次上传意图；重试沿用，新的业务操作使用新标识 |

输出包括文档标识、原始文件记录、初始内容版本、任务标识和受理结果。此时有效版本可以为空，页面应显示“已接收，待处理”。

## 正常业务流程

1. 校验登录状态、知识库写入权限、租户容量和当前上传额度。
2. 检查文件是否为空、实际内容是否符合允许类型、大小和页数是否超过限制。扩展名和浏览器声明只能作为参考。
3. 判断文件是否加密、损坏或需要特定解析能力。不具备处理能力时给出可执行的说明，例如要求提供可读取版本。
4. 生成安全的存储对象键，将文件保存到暂存区，核对长度与摘要。
5. 按请求标识查询是否已经受理。同一标识与相同业务参数返回原文档和任务；同一标识更换文件或知识库时返回冲突。
6. 可靠登记文档、版本、文件引用和待处理任务，再将文件确认为被业务记录引用。
7. 返回任务查询入口，由后台执行解析。浏览器关闭不应影响已受理任务。
8. 完成后展示“处理中、待审核、可用、失败”等状态和可操作入口。

数据库与对象存储通常不能靠同一事务提交。设计上应允许暂存文件、待绑定记录和补偿清理，避免把“对象已上传”误当作“任务已登记”。

## 重复上传与更新规则

| 情况 | 建议处理 |
| --- | --- |
| 网络超时后重复同一请求 | 返回同一文档与同一任务，避免重复收费和处理 |
| 同知识库内文件内容完全相同 | 提示已有文档，允许查看；是否允许另建业务文档由产品规则决定 |
| 文件名相同、内容不同 | 不自动覆盖，要求明确是新文档还是指定文档的新版本 |
| 内容相同、业务标题不同 | 标题不决定内容身份；按新增或元数据修改意图处理 |
| 跨租户内容相同 | 不暴露其他租户是否拥有该文件；存储去重不能等同业务合并 |

批量上传应逐文件受理并返回结果。一批中部分失败不应让成功项失去记录；页面同时显示成功、拒绝和待重试数量。

## 状态、页面与业务规则

上传表单至少展示目标知识库、标题、文件名、大小和上传进度。进度达到 100% 后切换到处理状态，不能直接显示“知识可用”。列表提供任务阶段、更新时间、失败原因和授权范围内的重试操作。

如果引入内容审核，上传人提交后进入待审核，审核通过才允许发布。自动发布知识库可以跳过人工审核，但不能跳过解析质量和索引完整性检查。

## 异常与恢复

| 异常 | 对用户的结果 | 恢复方式 |
| --- | --- | --- |
| 存储失败 | 未受理成功 | 重试同一请求或重新上传 |
| 文件保存成功但登记失败 | 结果待确认 | 查询请求记录，未绑定文件按保留期清理 |
| 登记成功但响应丢失 | 前端显示未知 | 用原请求标识查询，不能直接新建 |
| 队列通知失败 | 已受理、尚未执行 | 由持久任务扫描或可靠事件重新派发 |
| 上传后权限被撤销 | 后续发布被阻止 | 执行与发布时重新检查授权和文档状态 |

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 合法文件首次上传 | 只有一个文档版本和一个可查询任务 |
| 同请求并发提交两次 | 返回同一业务结果，不产生两份有效内容 |
| 文件名伪装为 PDF | 按实际内容拒绝或正确识别，不盲目进入解析 |
| 同名不同内容上传 | 不覆盖已有文档，明确新增或更新路径 |
| 请求成功后关闭页面 | 后台继续处理，重新进入可查状态 |
| 无权限用户修改知识库编号 | 无法写入其他知识库 |

## 实施前需要确定

确认允许的文件类型、容量与页数上限、暂存保留期、批量限制、重复内容策略，以及哪些知识库需要人工审核。这些限制应在表单与服务端使用同一业务口径。
