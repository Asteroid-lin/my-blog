# 知识源配置与授权

知识源配置定义“从哪里取、以谁的身份取、同步哪些内容、写入哪个知识库”。它是后续扫描和任务执行的业务依据。所属场景：[外部知识源同步](./README.md)。

## 角色与业务边界

租户管理员申请接入，源系统管理员授予服务身份访问范围，知识库管理员确认目标范围，运维人员维护连接和凭据。连接测试成功只能证明某些接口可访问，不能证明目标目录、文档下载和结果回写都具备权限。

源系统仍是文档内容和来源权限的权威依据。目标知识库可以施加更严格的访问限制；未经明确批准，不应把来源受限文档扩大为全员可见。

## 配置对象

| 项目 | 业务含义 |
| --- | --- |
| 配置标识、租户 | 确定归属及操作边界 |
| 来源类型与实例 | 区分不同文档平台、业务系统和环境 |
| 来源范围 | 空间、目录、知识库或经过授权的过滤规则 |
| 目标知识库 | 后端校验的固定映射，不能由任意请求覆盖 |
| 同步模式 | 全量初始化、增量扫描、手工触发或事件通知 |
| 调度规则 | 执行周期、时区、允许窗口和停机补扫规则 |
| 授权引用 | 指向部署环境或受控凭据服务中的凭据 |
| 配置修订号 | 使任务能够说明按哪一版配置执行 |
| 启用状态 | 控制是否允许产生新的同步任务 |

配置页面不保存或回显明文密钥。一般业务配置仅记录授权引用和验证状态，连接凭据由部署环境或受控凭据服务提供。

## 开通流程

1. 确认来源文档的业务负责人、使用目的、范围和目标知识库。
2. 创建最小范围的服务身份，区分列举目录、读取正文、下载文件和结果回写权限。
3. 保存未启用配置，校验租户、知识库、来源范围和参数完整性。
4. 分别测试目录访问、代表文档读取、文件下载、权限元数据读取；需要回写时再验证回写权限。
5. 试同步少量样本，核对标题、内容、来源链接和访问边界。
6. 管理员确认后启用配置，创建首次扫描批次。
7. 页面展示最近扫描、任务积压、授权有效性和失败原因。

启用配置与调度器可运行是两个条件。系统有调度 Bean、任务定义或定时表达式，不代表某个租户已经具备可执行配置。

## 修改、暂停与停用

| 操作 | 行为基线 |
| --- | --- |
| 调整扫描周期 | 新批次使用新周期，现有任务继续按原执行记录追踪 |
| 缩小来源范围 | 先计算影响清单，按退出范围规则停用相应目标文档 |
| 更换目标知识库 | 作为迁移处理，重新授权、建映射并清理旧目标 |
| 暂停扫描 | 停止创建新批次，已受理任务可继续；界面明确此语义 |
| 紧急停用连接 | 禁止继续读取来源，并取消或挂起未完成任务 |
| 凭据轮换 | 使用新凭据执行后续请求，保留轮换审计，不记录密钥内容 |

停止同步不会自动删除已同步内容。如果来源失去授权，已同步内容是否仍能使用需要按访问政策处理，不能仅依靠“停止扫描”实现撤权。

## 下载与网络边界

配置中指定可信来源，下载请求只访问允许的协议、主机和必要路径。重定向后仍需重新校验目标，并避免把来源凭据发送到其他域名。下载地址失效时重新申请授权地址，不能无限重用过期链接。

页面展示连接状态时使用脱敏地址和错误分类，不把带签名或凭据的完整 URL 放入日志和通知。

## 异常处理

授权过期应停止无效重试，提示管理员重新授权；来源限流进入退避并保留扫描进度；来源范围不可访问与目录不存在分别记录。目标知识库被删除或禁用时阻止任务发布，不能自动改投默认知识库。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 只授予列表权限 | 测试能指出下载或正文读取权限不足 |
| 配置属于租户 A，目标属于 B | 保存或启用失败 |
| 配置尚未启用 | 定时器不会产生正式同步任务 |
| 凭据失效 | 连接状态可定位，日志无密钥 |
| 修改目标知识库 | 展示迁移影响，旧文档不会悄悄失联 |
| 下载重定向到未授权主机 | 拒绝请求，不转发来源凭据 |

## 实施决策

确定支持的知识源、权限是否可同步、授权失效时的文档使用政策、连接暂停与紧急停用的区别，以及来源范围变更的审批责任。
