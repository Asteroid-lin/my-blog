# 文档停用、删除与索引清理

停用和删除首先解决知识是否还可以被使用，随后处理资源保留与清理。必须避免原文已经删除、索引和缓存仍能回答其中内容。所属场景：[知识更新与下线](./README.md)。

## 操作语义

| 操作 | 对问答的影响 | 对资源的影响 |
| --- | --- | --- |
| 停用 | 停止新检索和新引用使用 | 可保留原文与产物以便恢复或审计 |
| 逻辑删除 | 普通用户不可用 | 保留删除标记、必要历史与清理记录 |
| 物理清理 | 不恢复可见性 | 按政策删除文件、片段、索引及副本 |
| 重新启用 | 经校验后恢复使用 | 需要有效内容、权限和完整索引 |
| 恢复已删除文档 | 独立的受控操作 | 取决于保留期及资源是否仍存在 |

停用不等于原文已经销毁，删除受理也不等于所有副本已清理。页面需要分别报告访问状态与清理进度。

## 正常下线流程

1. 验证维护权限，确认文档、操作类型、原因和期望修订。
2. 对批量操作生成影响清单，包括来源同步关系、索引、引用和未完成任务。
3. 提交停用或删除标记，更新访问判断与文档操作代次。
4. 阻断新问答与原文访问，失效相关缓存和派生答案复用。
5. 取消或标记过期的入库、更新、发布任务，防止迟到结果重新启用。
6. 登记分资源清理任务：索引、片段、解析产物、原文件和必要副本。
7. 执行清理并逐项确认，不存在的目标可作为幂等成功处理。
8. 汇总完成结果，保留必要审计与删除标记，供来源重扫和灾后恢复识别。

下线标记是访问阻断依据，不能等待物理删除全部成功才生效。

## 来源同步与重新出现

源文档仍存在时，本地删除后下一次扫描可能再次发现。必须定义删除范围：只是移除当前副本，还是停止该来源文档继续同步。

需要持续排除时保留来源映射或排除标记，由有权限的人解除。若决定重新同步，应形成新的恢复或导入操作，不能把旧删除记录悄悄覆盖掉。来源明确恢复文档也需要符合当前授权与目标策略。

## 清理资源与证据

| 资源 | 清理要求 |
| --- | --- |
| 关键词与向量索引 | 按文档和相关版本清理，并核对无残留可召回内容 |
| 片段、解析产物 | 检查历史引用和保留规则后处理 |
| 原始文件 | 确认不再被其他合法业务引用 |
| 缓存与摘要 | 按来源依赖失效，不能只清索引 |
| 历史会话 | 按访问政策隐藏、限制或保留受控记录 |
| 备份与归档 | 按独立保留计划处理，记录到期与恢复后再次删除要求 |

物理去重的对象可能被多个文档引用，清理时需要引用核对，不能删除一个业务文档就移除其他文档仍依赖的文件。备份恢复后应重新应用有效的删除与撤权记录，防止旧知识复活。

## 在途问答与恢复启用

问答输出前检查文档是否下线；流式场景按照既定中断政策处理，已发送内容不能自动收回。历史答案不能因为删掉引用按钮就认定正文不再含下线知识。

重新启用时检查来源授权、文档权限、当前内容适用性与索引完整性；产物已清理则重建。仅把状态从停用改成可用，无法证明检索设施已恢复。

## 异常与补偿

| 情况 | 处理 |
| --- | --- |
| 访问已阻断、索引清理失败 | 保持阻断，独立重试清理 |
| 外部删除超时 | 查询是否仍存在，再幂等删除 |
| 清理时发现共享文件引用 | 保留文件，仅移除当前引用 |
| 更新任务晚到 | 校验操作代次，拒绝发布并清理残留 |
| 误删除需要恢复 | 根据保留策略创建恢复任务并审核 |
| 批量部分失败 | 保留逐文档结果，重试失败项 |

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 停用后立即提问 | 不能使用该文档，即使索引未清理 |
| 删除期间旧任务完成 | 文档不被重新启用 |
| 来源重扫再次发现文档 | 遵循排除或恢复策略 |
| 删除共享文件的一份文档 | 其他合法引用仍可用 |
| 索引删除响应丢失 | 能核对最终状态，不误报全部完成 |
| 从备份恢复 | 删除和撤权规则重新生效 |

## 实施决策

确定停用、软删和物理清理权限，删除保留期、来源排除规则、历史答案政策、共享对象清理方法和备份处理边界。
